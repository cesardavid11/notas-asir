# Variable

**Date:** 2026-09-9
**Category:** (Python)

Think of a variable as a labeled container or box in your computer's memory. You put a piece of data inside the box, put a name on the outside, and then use that name whenever you want to access or change what's inside.

---

## 1. Creating a Variable
In Python, you create a variable by giving it a name and assigning it a value using the equals sign (=):

```
age = 25
name = "Alex"
is_student = True
```


## 2. Using and Updating Variables
Once a variable is created, you can use its name in place of the value, or overwrite it with a new value later:

```
score = 10
print(score)  # Prints: 10

# Update the value inside the variable
score = 15
print(score)  # Prints: 15
``` 

## 3. Rules for Variable Names
Must start with a letter or an underscore _ (e.g., user_name, _count).

* Cannot start with a number (e.g., 1variable is invalid).

* Can only contain alphanumeric characters and underscores (A-z, 0-9, and _).

* Case-sensitive (age, Age, and AGE are three completely different variables).
