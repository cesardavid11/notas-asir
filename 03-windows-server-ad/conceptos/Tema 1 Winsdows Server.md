## ¿Que es Windows Server?

Windows Server es un sistema operativo desarrollado por Microsoft diseñado para administrar redes, aplicaciones, servicios empresariales y almacenamiento centralizado.

* **Función principal:** Permite a los administradores de TI gestionar permisos de usuarios, almacenar archivos de forma centralizada, hospedar páginas o aplicaciones web y garantizar la seguridad de la red.

* **Servicio estrella (Active Directory):** Es la herramienta principal de Windows Server. Funciona como una base de datos centralizada que gestiona la identidad y los permisos de todos los usuarios y equipos de una empresa.

* **Gestión de Red:** Proporciona servicios esenciales de red como DHCP (asignación automática de direcciones IP) y DNS (traducción de nombres de dominio a direcciones IP).

* **Virtualización:** Incluye Hyper-V, una tecnología integrada para crear y ejecutar máquinas virtuales dentro del mismo servidor.

* **Diferencia clave con Windows de escritorio**: Mientras que Windows 11 está optimizado para la interfaz gráfica, juegos y tareas personales, Windows Server está optimizado para estar encendido 24/7, procesar múltiples solicitudes simultáneas y ejecutarse con estabilidad y seguridad avanzadas.
